NETDES // EB1-EB2 campus

CAMPUS NETWORK DESIGNFaculty of Education, buildings EB1 and EB2

A full design from a real site survey: 722 peak users and 1,668 devices across two three-storey buildings, 57 controller-based Wi-Fi 6 APs, one firewall HA pair as the only Layer 3 point, and a sourced budget. Every number on this page is generated from the repository's design file and checked automatically.

Architecture

  • 3-tier with a core in each building; EB1 needs 2 inter-building links instead of 6.
  • FortiGate 200F HA pair is the gateway for all 14 VLANs; every switch is Layer 2.
  • 2x10G LACP uplinks; OM4 inside buildings, OS2 on two diverse paths between them.
  • Rapid-PVST+ with the faculty core as root; Root Guard toward access.

Why it holds up

  • AP count = max(coverage, capacity): EB1302 needs 450 Mbps, so 3 APs.
  • Highest PoE load 73% of budget; 161 spare access ports.
  • One surviving uplink still carries the busiest floor (0.8 Gbps).
  • Firewall 3 Gbps vs 2.26 Gbps planned egress.

Trade-offs accepted

  • EB2-F2-DS01 serves two floors (a second member costs about THB 111,000).
  • Single WLC (HA SSO adds about THB 140,000).
  • Two firewalls, not one (+THB 388,500) to remove the single exit point.

Edge and wireless

  • FortiGate NGFW HA: firewall, IPS, AV, web filter, app control
  • WPA3-Enterprise 802.1X with PMF; OWE + captive portal for guests
  • Rogue AP detection on the controller

Access and management

  • DHCP snooping, Dynamic ARP Inspection, BPDU Guard, Root Guard
  • Sticky port security on CCTV and IoT ports; unused ports shut in VLAN 999
  • SSH v2, HTTPS and SNMPv3 only, through VLAN 10

Campus network, Faculty of Education EB1 and EB2

Two three-storey buildings, 722 peak users and 1,668 devices. A three-tier design with a core in each building and one firewall HA pair as the only Layer 3 point, from a site survey through to a sourced bill of materials.

B

Design notes

Architecture

  1. Three tiers with a core in each building, so EB1 needs two inter-building links instead of six.
  2. The FortiGate 200F HA pair is the gateway for all 14 VLANs. Every switch is Layer 2.
  3. Uplinks are 2×10G LACP: OM4 inside buildings, OS2 on two diverse paths between them.
  4. Rapid-PVST+ with the EB2 core as root and Root Guard toward access.

Sizing basis

  1. APs per room = max(coverage, capacity). EB1302 needs 450 Mbps, so it gets 3 APs.
  2. Highest PoE load is 73% of the switch budget, with 161 spare access ports.
  3. One surviving uplink still carries the busiest floor (0.8 Gbps).
  4. Firewall throughput 3 Gbps against 2.26 Gbps planned egress.

Accepted trade-offs

  1. EB2-F2-DS01 serves two floors; a second member would cost about THB 111,000.
  2. One wireless controller; HA SSO would add about THB 140,000.
  3. Two firewalls rather than one (+THB 388,500) to remove the single exit point.

Edge and wireless

  1. FortiGate NGFW HA: firewall, IPS, antivirus, web filter and application control.
  2. WPA3-Enterprise 802.1X with PMF; OWE with a captive portal for guests.
  3. Rogue AP detection on the controller.

Access and management

  1. DHCP snooping, Dynamic ARP Inspection, BPDU Guard and Root Guard.
  2. Sticky port security on CCTV and IoT ports; unused ports shut in VLAN 999.
  3. SSH v2, HTTPS and SNMPv3 only, through VLAN 10.
